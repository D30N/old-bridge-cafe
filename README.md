# Old Bridge Cafe — Menu Website

The online menu for **Old Bridge Cafe**, Oldbridge, Murinjapuzha.

**Live site:** https://d30n.github.io/old-bridge-cafe/

Open daily · 11:00 AM – 11:00 PM

## What's on the site

- **Full menu** — 12 categories (Lime, Shake, Mojito, Juice, Lassi, Falooda, Tea, Fruit Salad, Kannur Cocktail, Aval Milk, Cold Coffee, Kulukki) with a photo page and price list for each
- **Live weather header** — the header animates with the actual weather at Murinjapuzha (rain, drizzle, storm with lightning, sun, clouds, fog, night sky) and shows the current temperature and condition
- **Today's Special marquee** — a scrolling strip under the header, updated by the cafe through a Telegram bot — the admin sends a message and it appears on the site in 1–2 minutes; sending OFF hides it
- **Malayalam / English** — a language switch (English | മലയാളം) above the search bar translates the menu content; the choice is remembered per visitor
- **Menu search** — filters categories as you type and lists matching items with prices, in both languages
- Menu only — no online ordering

## Tech

- Plain static HTML/CSS/JS, hosted on **GitHub Pages**
- The whole site is generated by a single Python file — [`build.py`](build.py) — no frameworks, no build dependencies
- Weather data: [Open-Meteo](https://open-meteo.com/) (no API key)
- Visitor stats: GoatCounter (private)

## Rebuild

```bash
python3 build.py   # regenerates index.html + the 12 category pages
```

Commit and push — GitHub Pages deploys automatically.

## The special-marquee bot

`bot/special_bot.py` is a small stdlib-only Python bot that long-polls Telegram. An authorised admin's message becomes `special.json` in this repo (committed and pushed automatically), which the homepage fetches to render the marquee. It runs as a systemd service (`bot/obc-special-bot.service`). The bot token lives in `bot/config.json`, which is **not** tracked in git.
